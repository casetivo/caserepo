A strong password is long, unique, and difficult to guess. The most important rule is not complexity alone: do not reuse the same password across different services.

## What makes a password strong?

Use a long random password or a memorable passphrase with several unrelated words. A password manager can generate and store unique credentials for every account. Enable multi-factor authentication whenever it is available.

Avoid names, birthdays, predictable substitutions such as `@` for `a`, and reused passwords. If one reused password appears in a breach, attackers may try it on other services.

## FAQ

### How long should a password be?

Longer is generally better. Use the maximum length supported by the service, especially for important accounts.

### Should I change passwords regularly?

Change a password when you suspect compromise, receive a breach alert, or reuse it elsewhere. Unique passwords and MFA are more valuable than arbitrary frequent changes.
