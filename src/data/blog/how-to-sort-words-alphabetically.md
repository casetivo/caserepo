Alphabetizing a long list by hand is slow and easy to get wrong. Whether you are preparing a glossary, contact list, keyword list, or classroom resource, a sorter gives you a consistent A–Z result in seconds.

## How to alphabetize a list

1. Put each word, name, or item on its own line.
2. Paste the list into the [Sort Words Alphabetically](/sort-words-alphabetically) tool.
3. Choose ascending or descending order.
4. Copy the sorted list.

For example, `zebra`, `apple`, and `mango` become `apple`, `mango`, and `zebra` in ascending order.

## Tips for cleaner results

- Remove duplicate entries before sorting with the [Duplicate Line Remover](/duplicate-line-remover).
- Keep one item per line; comma-separated lists can be harder to review.
- Decide whether numbers should be treated as text or values before sorting a mixed list.
- Standardize inconsistent capitalization when required with the [Lowercase Converter](/lower-case).

## FAQ

### Can I sort names by last name?

For best results, format names consistently first, such as `Last name, First name`, then sort the lines.

### Does alphabetizing change the words?

No. A sorter changes the order of the lines; it does not rewrite the text itself.
