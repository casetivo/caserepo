It is frustrating when a password generator creates a password that a website refuses. The password may still be strong; the site may simply have different formatting rules.

## Common reasons a password is rejected

- It is shorter or longer than the site's allowed range.
- The site requires a number, uppercase letter, lowercase letter, or symbol.
- A selected symbol is not permitted by that website.
- The password contains a space or character the site does not support.
- The password matches a previously used or known-compromised password.

## How to generate an accepted password

Read the requirement message, then set the correct length and character categories in the [Strong Password Generator](/strong-password-generator). The generator ensures each enabled category appears at least once. If symbols cause a problem, turn them off and generate a fresh, long password instead.

Never make a rejected password work by reusing an old one. Save the accepted new password in a password manager.

## FAQ

### Should I remove all symbols if a website rejects one?

Only if the site does not explain which symbols it allows. Try a new password with a simpler allowed character set and sufficient length.

### Why does a website say my password is too common?

Many sites block passwords found in breach lists or common-password databases. Generate a new unique password instead of adding a predictable number to the rejected one.
